# 🛡️ Cybersecurity Labs | Cisco & Mujer Digital 

Bienvenido/a a mi repositorio de ciberseguridad. Aquí documento mis prácticas, análisis de tráfico y laboratorios técnicos desarrollados durante mi programa técnico intensivo de 5 meses con **Mujer Digital** y **Cisco Networking Academy**.

## Módulos y Rutas de Aprendizaje

Actualmente, este repositorio contiene evidencia y apuntes de los siguientes temas:

*   **Introducción a la Ciberseguridad:** Fundamentos del campo, análisis del panorama actual de amenazas y proyección profesional.
*   **Conceptos Básicos de Redes:** Arquitectura de redes de computadoras, flujos de datos y comprensión de protocolos.
*   **Dispositivos de Red y Configuración Inicial:** Despliegue de topologías básicas y configuración práctica de hardware de red.
*   **Seguridad de Endpoints (Terminales):** Estrategias y controles para proteger la red desde el borde hasta los dispositivos finales.
*   **Trayecto Profesional:** Notas de tutorías, desarrollo de soft skills y visión de carrera.

## Estructura del Repositorio

*   `laboratorios-y-practicas/` -> Capturas de red (Wireshark), simulaciones de topologías y ejercicios técnicos.
*   `resumenes-teoricos/` -> Notas de estudio, diagramas y conceptos clave extraídos de los módulos y tutorías.

## Herramientas y Tecnologías
*   Wireshark (Análisis de tráfico de red)
*   Cisco Packet Tracer (Simulación y configuración)
*   Conceptos de Seguridad Defensiva y Redes
