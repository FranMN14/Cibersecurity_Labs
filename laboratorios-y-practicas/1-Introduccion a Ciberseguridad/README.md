# Introducción a la Ciberseguridad - Notas y Laboratorios

## Descripción
Este repositorio contiene mis resúmenes, notas de estudio y reportes de laboratorios desarrollados durante el curso de Introducción a la Ciberseguridad. El objetivo de este espacio es documentar mi aprendizaje sobre los conceptos fundamentales de seguridad informática, análisis de riesgos y buenas prácticas de protección de datos.

---

## Contenido del Repositorio

| Laboratorio / Tema | Descripción Principal |
| :--- | :--- |
| **Términos de Servicio y Privacidad** | Análisis de contratos en línea, políticas de uso de datos y configuraciones de privacidad por defecto. |
| **Ingeniería Social y Buenas Prácticas** | Identificación de riesgos en redes sociales, uso de VPN, gestores de contraseñas y detección de correos de phishing. |
| **Escaneo de Puertos con Nmap** | Conceptos básicos de puertos en red, uso de Nmap/Zenmap para escaneo local y verificación de puertos expuestos en IP pública. |
| **¿Quién posee sus datos?** | Evaluación de propiedad de datos en la nube, derechos de usuario y técnicas para proteger la información personal. |

---

## Conceptos Clave Aprendidos

* **Confidencialidad y Privacidad:** Importancia de revisar políticas de uso de datos y ajustar la configuración de perfil a privado.
* **Gestión de Identidades:** Uso de autenticación de dos pasos (2FA) y gestores de contraseñas para evitar el rehuso de credenciales.
* **Seguridad en Redes:** Fundamentos de escaneo de puertos para identificar servicios activos y uso de VPN en conexiones públicas.
* **Prevención de Amenazas:** Reconocimiento de técnicas de ingeniería social como phishing y scareware.

---

## Herramientas Utilizadas

* **Nmap / Zenmap:** Para escaneo y reconocimiento de puertos en red.
* **Wireshark:** Para análisis de tráfico y paquetes de red.
* **Gestores de Contraseñas y VPN:** Como medidas de protección personal y acceso remoto seguro.
